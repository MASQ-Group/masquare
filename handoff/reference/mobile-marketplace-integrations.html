Proposal
Mobile web view — Marketplace integrations
Same mobile pattern as Sales transactions: compact sticky bar with summary strip, one-row toolbar, and cards instead of horizontally-scrolling tables.
1 · Sticky bar, same recipe. Title row with icon-only Sync all, ⋯ overflow (auto-sync settings, Pull older orders, Secrets) and a shortened "+ Add" primary. On scroll-down it collapses to a 34px health summary — 20 connections · 18 healthy · 2 attention — so status is always visible and there's no dead gap.
2 · KPI cards → one compact 4-up row. The four big stat cards become a single row of mini-stats (2×2 stacking cost too much height). Attention/error counts keep their colors as the signal.
3 · Auto-sync panel → one summary strip. Time picker, save, toggle and Pull older orders collapse into a one-line status ("Auto-sync off · daily 05:00 UTC · 0/20 on") with Configure opening a bottom sheet with the full controls.
4 · Group tables → account cards. Each connection is a 2-line row: name + active badge, then health + last sync + change chip in one line. Status/Health/Last-sync columns fold into it — no horizontal scrolling. Sync stays as a per-row button; everything else moves to the row's ⋯.
5 · Group header stays scannable. Marketplace logo, count, healthy/verify dots, and one ⋯ for group actions (Auto-sync toggle, Older orders, Sync group).
