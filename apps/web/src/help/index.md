# Help

The platform is a chain of connected parts: what you buy becomes stock, stock becomes a listing,
a listing becomes an order, and an order becomes a number in Analytics. Most confusion comes from
the joins rather than the screens, so this help is organised around them.

## Where to start

**Processes** are the most useful pages and the place to begin. Each follows one thing all the way
through, across every module it touches — how a cost becomes a margin, what may change a stock
figure, where the money goes when an order comes back. If something is producing a number you did
not expect, the answer is usually on one of these.

**Modules** describe one area at a time, and match the access areas exactly. If you can open a
screen, there is a page here for it.

**Reference** is generated from the platform itself, so it cannot fall out of step: the access
areas and capabilities, the roles, the reasons a stock movement can carry.

## A note on trust

Every page names the code it describes and the date it was last checked against it. When the code
moves and the page has not been reviewed, a test fails — so a page that is wrong is a build
problem rather than something you discover the hard way.

Pages still to be written are listed with what they will cover rather than quietly omitted, so you
can tell the difference between *not documented* and *nothing to say*.
